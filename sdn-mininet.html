1 — Introduction

Sécurité SDN par simulation et détection automatisée

Ce projet virtualise un environnement réseau complet, simule des attaques réalistes (ARP Spoofing, DDoS ICMP Flood) et implémente leur détection automatique via le contrôleur SDN POX programmé en Python.

3 — Contrôleur POX

POX — Cerveau du réseau SDN

POX contrôle le réseau via OpenFlow 1.0. Il supervise, analyse et sécurise tout le trafic réseau en temps réel.

📡
Supervision OpenFlow
Gestion centralisée des switches via règles flow_mod installées dynamiquement.
🔍
Analyse PacketIn
Analyse de chaque paquet lors de l'événement PacketIn pour détecter les comportements suspects.
🔒
Blocage dynamique
ofp_flow_mod sans action = DROP silencieux sur les MAC suspectes. Priorité 1000.
⚡
Réponse automatique
Détection et blocage en temps réel sans intervention humaine. Thread cleaner pour expiration.

class FirewallController:
    def __init__(self, connection):
        self.arp_table    = {}   # {ip → mac}
        self.flow_counter = {}   # {src_mac → [timestamps]}

    def handle_arp(self, event, packet, in_port):
        # Détecte incohérence IP → MAC dans arp_table
        if ip in self.arp_table and self.arp_table[ip] != mac:
            log.warning("[ARP Spoofing] %s: %s → %s", ip, self.arp_table[ip], mac)

5 — ARP Spoofing

ARP Spoofing — Empoisonnement du cache ARP

L'attaquant envoie de faux ARP Replies bidirectionnels pour s'intercaler entre la cible et sa passerelle (MITM). POX détecte l'incohérence IP ↔ MAC et bloque immédiatement.
Étape 01
Empoisonnement
Envoi continu de faux ARP Replies via Scapy (1 pkt/seconde).
Étape 02
Interception MITM
Tout le trafic transite par l'attaquant.
Défense POX
Détection & Blocage
Incohérence détectée → DROP immédiat sur la MAC suspecte.
Pipeline Détection ARP
1
Attaquant envoie ARP Replies falsifiés en continu
2
POX reçoit via PacketIn et vérifie son arp_table
3
WARNING: [ARP Spoofing] Conflicting mapping for 10.0.2.12
4
block_host(mac) → règle DROP priorité 1000 installée

6 — DDoS

DDoS ICMP Flood — Saturation du serveur web

Envoi massif de requêtes ICMP (150 pps) pour saturer le serveur web. POX comptabilise les flux par hôte et bloque dès le dépassement du seuil.
Seuil
20 flux / 10 secondes
Configurable via CLI POX : --dos_threshold=10 --dos_window=2.0
Script
icmp_load.py --pps 150
Scapy envoie 150 paquets ICMP/seconde vers websrv pendant 15 secondes.
Résultat
Attaquant isolé
Règle DROP installée. Serveur web redevient accessible aux clients légitimes.
