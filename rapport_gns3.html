Introduction

Un laboratoire de cybersécurité réaliste

Ce document présente, étape par étape, la création d'un laboratoire de cybersécurité dans GNS3. L'architecture couvre la segmentation VLAN, la haute-disponibilité de pare-feu (HA), un contrôleur de domaine Active Directory, et un serveur web en DMZ.

Objectifs du projet

Simuler un environnement d'entreprise sécurisé dans GNS3
Mettre en place un cluster de deux FortiGate en mode HA active-passive
Segmenter le réseau en VLANs (LAN, DMZ, Internet)
Déployer un contrôleur de domaine Windows avec GPO
Héberger un site web vulnérable (DVWA) sur Ubuntu en DMZ pour des scénarios de test d'intrusion

Section 7

Règles de pare-feu

Les règles définissent les flux autorisés entre les zones LAN, DMZ et Internet. Configuration dans Policy & Objects → Firewall Policy.

RègleSourceDestinationServiceActionNAT
LAN1_To_WAN VLAN 10 all ALL ✓ ACCEPT ON
lan2_to_lan1 VLAN 20 VLAN 10 ALL ✓ ACCEPT —
lan2 → WAN VLAN 20 all ALL ✓ ACCEPT ON
Dmz_to_wan VLAN 30 all ALL ✓ ACCEPT ON
Block_DMZ_lan1 VLAN 30 VLAN 10 ALL ✗ DENY —
block_dmz_lan2 VLAN 30 VLAN 10 + 20 ALL ✗ DENY —
✓ Logique sécurité La DMZ peut accéder à Internet mais pas aux réseaux LAN internes. Les VLANs LAN peuvent communiquer entre eux et avec Internet via NAT. Isolation complète de la zone DMZ.

Le rôle AD DS centralise la gestion des utilisateurs, groupes, ordinateurs et stratégies de sécurité dans l'environnement Windows Server.

10.1 Installation Active Directory AD DS

Via Server Manager → Add Roles → AD DS. Après installation, promotion du serveur en contrôleur de domaine.

10.3 GPO — Blocage des installeurs

Stratégie de groupe pour empêcher les utilisateurs d'installer des logiciels depuis les dossiers restreints.

Ouvrir la console GPMC · Créer une nouvelle GPO
Navigation : Configuration ordinateur → Paramètres Windows → Paramètres de sécurité → Stratégies de contrôle des applications
Créer une nouvelle règle de chemin avec le path : C:\Users\*\Downloads\
Les utilisateurs ne peuvent plus exécuter d'installateurs depuis les dossiers restreints
✓ Résultat GPO appliquée avec succès — politique de sécurité centralisée sur tous les postes du domaine lab.local.
