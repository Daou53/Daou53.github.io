Samba — Contrôleur de domaine Linux

Configuration de Samba 4 sur Ubuntu/Debian comme contrôleur de domaine Active Directory alternatif. Permet l'intégration de postes Windows dans un environnement Linux.

bash — Installation Samba
sudo apt -y install samba krb5-config winbind smbclient
sudo mv /etc/samba/smb.conf /etc/samba/smb.conf.original
sudo samba-tool domain provision
# Realm : TP.LAB | Domain : TP | Server Role : dc
sudo cp /var/lib/samba/private/krb5.conf /etc/
bash — Création utilisateur & test
sudo samba-tool user create daouda
# Test connectivité
ping -c3 tp.lab
host -t a tp.lab
# → tp.lab has address 192.168.188.128

Partages Samba

bash — /etc/samba/smb.conf
[Mon-partage]
  path = /home/daou/Desktop
  browseable = yes
  read only = no

[imprimante]
  path = /var/spool/samba
  printable = yes
  guest ok = yes
✅ Partages accessibles depuis Windows via \\192.168.72.130\Mon-partage
03

Supervision avec Zabbix 6.4

Déploiement de Zabbix 6.4 sur Ubuntu 22.04 avec base de données MySQL et serveur web Apache. Supervision de machines Windows et Linux via agents Zabbix.

bash — Installation Zabbix
wget https://repo.zabbix.com/zabbix/6.4/ubuntu/pool/main/z/zabbix-release/zabbix-release_6.4-1+ubuntu22.04_all.deb
dpkg -i zabbix-release_6.4-1+ubuntu22.04_all.deb
apt install zabbix-server-mysql zabbix-frontend-php zabbix-apache-conf zabbix-agent
sql — Création base de données
CREATE DATABASE zabbix CHARACTER SET utf8 COLLATE utf8_bin;
CREATE USER zabbix@localhost IDENTIFIED BY 'password';
GRANT ALL PRIVILEGES ON zabbix.* TO zabbix@localhost;
FLUSH PRIVILEGES;
✅ Interface Zabbix accessible sur http://ip_server/zabbix — 3 hôtes supervisés : Zabbix server, PC Windows, Ubuntu Client
04

Surveillance MySQL & Alertes Mail

Configuration d'un déclencheur Zabbix pour surveiller la disponibilité du service MySQL. En cas d'indisponibilité, une alerte mail est envoyée automatiquement à l'administrateur.

sql — Utilisateur de surveillance
CREATE USER 'zbx_monitor'@'%' IDENTIFIED BY 'DevOpsSchool$123';
GRANT REPLICATION CLIENT,PROCESS,SHOW DATABASES,SHOW VIEW ON *.* TO 'zbx_monitor'@'%';
FLUSH PRIVILEGES;

Déclencheur configuré : si MySQL ne répond pas pendant plus de 5 minutes → alerte de sévérité Haute → envoi mail SMTP.

Test de validation : arrêt du service MySQL → mail reçu en moins d'1 minute avec détails de l'incident. Redémarrage → mail de résolution automatique envoyé.

✅ Chaîne complète validée : panne simulée → détection Zabbix → alerte mail → résolution automatique notifiée.
