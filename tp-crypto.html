01

Chiffrement de César

Le code de César est un chiffrement par substitution où chaque lettre est remplacée par une lettre décalée d'un nombre fixe de positions dans l'alphabet.

Principe
Si décalage = 3 : A→D, B→E, C→F... "BONJOUR" devient "ERQMRXU". Pour décoder, on applique le décalage inverse (-3).
python — position(x)
def position(caractere):
    alphabet = 'abcdefghijklmnopqrstuvwxyz'
    if caractere.lower() in alphabet:
        return alphabet.index(caractere.lower()) + 1
    else:
        return -1
python — decalage(x, n)
def decalage(x, n):
    if 'a' <= x <= 'z':
        n_position = (ord(x) - ord('a') + n) % 26
        return chr(ord('a') + n_position)
    elif 'A' <= x <= 'Z':
        n_position = (ord(x) - ord('A') + n) % 26
        return chr(ord('A') + n_position)
    else:
        return x
python — codage(texte, n)
def codage(texte, n):
    code = ""
    for i in range(len(texte)):
        if position(texte[i]) == -1:
            code = code + texte[i]  # caractère non codé (ponctuation etc.)
        else:
            code = code + decalage(texte[i], n)
    return code

# Test
texte_claire = "Bonjour, daouda!"
texte_code = codage(texte_claire, 3)
# → "Erqmrxu, gdrxgd!"
02

Cryptanalyse par Analyse de Fréquence

La lettre la plus fréquente en français est le 'e'. Si on connaît la lettre la plus fréquente du texte chiffré, on peut déduire le décalage et décoder le message.

python — plus_frequent(texte)
def plus_frequent(texte):
    alphabet = 'abcdefghijklmnopqrstuvwxyz'
    occurrences = {char: texte.count(char) for char in alphabet}
    Cmax = max(occurrences, key=occurrences.get)
    return Cmax
python — decryptage(code)
def decryptage(code):
    frequent_char_in_code = plus_frequent(code)
    shift = ord(frequent_char_in_code) - ord('e')
    decrypted_text = ''
    for char in code:
        if char.isalpha():
            if char.isupper():
                decrypted_text += chr((ord(char) - shift - ord('A')) % 26 + ord('A'))
            else:
                decrypted_text += chr((ord(char) - shift - ord('a')) % 26 + ord('a'))
        else:
            decrypted_text += char
    return decrypted_text
Résultat : Avec un texte long chiffré avec un décalage aléatoire (1-25), l'algorithme retrouve automatiquement le texte original en supposant que la lettre la plus fréquente est 'e'.
03

Substitution Mono-alphabétique

Chiffrement plus robuste que César : chaque lettre est remplacée par une lettre définie dans une table de substitution. Exemple : A→W, B→X, C→E...

python — codage_substitution_mono_alph
def codage_substitution_mono_alph(texte_clair, table_substitution):
    texte_clair = texte_clair.lower()
    texte_chiffre = ""
    for caractere in texte_clair:
        if caractere.isalpha():
            indice = ord(caractere) - ord('a')
            texte_chiffre += table_substitution[indice]
        else:
            texte_chiffre += caractere
    return texte_chiffre

# Test
table_substitution = "wxehyztkcpj1uadglmnrsvbo"
texte_clair = "il fait beau"
# → "kp zwkn zywn"
python — decodage_substitution_mono_alph
def decodage_substitution_mono_alph(texte_chiffre, table_substitution):
    texte_chiffre = texte_chiffre.lower()
    texte_clair = ""
    for caractere in texte_chiffre:
        if caractere.isalpha():
            indice = table_substitution.index(caractere)
            texte_clair += chr(indice + ord('a'))
        else:
            texte_clair += caractere
    return texte_clair
04

Chiffre de Vigenère

Principe de Blaise de Vigenère
La clé est répétée sur toute la longueur du texte. Chaque lettre du texte est décalée du nombre correspondant à la lettre de la clé à la même position. Beaucoup plus résistant au César car le même caractère peut être chiffré différemment selon sa position.
python — Vigenere(texte, cle)
def Vigenere(texte, cle):
    code = ""
    p = len(cle)
    for i, char in enumerate(texte):
        if char.isalpha():
            k = position(cle[i % p])  # décalage = position de la lettre de clé
            code += char if k == -1 else decalage(char, k)
        else:
            code += char
    return code

# Exemple : texte="BONJOUR" cle="CLE"
# B+C=E, O+L=Z, N+E=R, J+C=M, O+L=Z, U+E=Y, R+C=U
# → "EZRMZYU"
Sécurité : Le chiffre de Vigenère est plus robuste que César car la même lettre du texte clair peut produire des lettres chiffrées différentes. Il peut néanmoins être cassé par l'indice de coïncidence ou la méthode de Kasiski pour trouver la longueur de la clé.
